成绩单签名验证

最省事的用法：把学生发来的 transcript-*-signed.json 整个文件用记事本打开， 全文复制粘贴到下面的「完整 JSON」框，直接提交即可。

验证页只判断“是否为本校签发、内容有没有被改”，不显示成绩内容。 签名只证明来源与完整性，不提供机密性（成绩单本身是明文）。

整段粘贴时会自动取出 payload 与 signature，不需要手工拆字段。
只贴 payload 时，请务必贴“不带反斜杠”的原文：从 JSON 文件里直接复制会带 \"， 那是 JSON 转义，页面会尝试自动纠正，但会可靠得多的是直接用上面的完整 JSON。
验证结果

签名算法：RSASSA-PSS · 证书指纹（SHA-256 前 16 字节）：-

验签不通过？按这个顺序排查

  1. 是不是只复制了 payload 字段、却带着 \" 转义？ 改用上面的「完整 JSON」整段粘贴。
  2. 下载文件里的 certificateFingerprint 与页面底部显示的指纹是否一致？ 不一致说明学校换过签名密钥（开发环境重启时若没有 keystore 会生成临时密钥）。
  3. 内容是否被改过（哪怕一个空格、一个数字、一个换行）？签名对字节敏感。
  4. 签名是否完整（Base64 一般 344 字符，别漏掉结尾的 =）。
