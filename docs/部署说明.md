# 部署说明（University Website）

本项目位于 algs4 根工程下，是一个 Spring Boot 2.7（Java 8）+ Spring MVC + MyBatis + Thymeleaf + Bootstrap 的大学网站，业务包为 `com.ds.university`。

## 1. 环境要求

| 软件 | 版本 | 说明 |
| --- | --- | --- |
| JDK | 1.8+ | 项目 `pom.xml` 配置 `java.version=1.8`，请勿使用 JDK 17+ 直接运行 Spring Boot 2.7 |
| Maven | 3.6+ | 构建与依赖管理 |
| MySQL | 8.0 | 业务库 `university`（含示例数据 + 账号权限表） |
| IDE | IntelliJ IDEA 等 | 直接运行 `UniversityApplication` |

## 2. 数据库初始化

数据库脚本位于 `src/main/resources/sql/`：

| 脚本 | 作用 |
| --- | --- |
| `university.sql` | 建库 `university` + 11 张业务表 + 示例数据（脚本开头会 `DROP DATABASE IF EXISTS university`，会清空已有数据） |
| `university_auth.sql` | 追加 5 张 `sys_*` 账号/角色/权限表 + 3 个演示账号（依赖先执行 `university.sql`） |

连接配置读取 `src/main/resources/db.properties`（默认 `root/root:3306`）。

方式一（推荐，一条命令完成两段脚本 + 结构验证）：

```bash
mvn -q compile
java -cp "target/classes;target/cp.txt" com.ds.db.UniversityDbSetup
```

> 若 `target/cp.txt` 不存在，先执行
> `mvn -q org.apache.maven.plugins:maven-dependency-plugin:3.6.1:build-classpath -Dmdep.outputFile=target\cp.txt`

方式二（手动执行 SQL，Windows 下可用项目自带的 `sql.bat`）：

```bat
sql.bat -f src\main\resources\sql\university.sql
sql.bat -f src\main\resources\sql\university_auth.sql
```

方式三（直接用 MySQL 客户端）：

```bash
mysql -uroot -proot < src/main/resources/sql/university.sql
mysql -uroot -proot < src/main/resources/sql/university_auth.sql
```

## 3. 应用配置

`src/main/resources/application.yml` 中数据源默认：

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/university?useUnicode=true&characterEncoding=UTF-8&serverTimezone=Asia/Shanghai&useSSL=false&allowPublicKeyRetrieval=true
    username: ${DB_USER:root}
    password: ${DB_PASSWORD:root}
```

- 端口默认 `8080`，可用环境变量或命令行覆盖：`--server.port=8081`。
- 账号密码可用环境变量 `DB_USER` / `DB_PASSWORD` 覆盖，不必改文件。
- 开发期已开启 `thymeleaf.cache=false` 与 `spring-boot-devtools`（改代码自动重启）。

## 4. 启动应用

方式一：IDE（推荐）

1. 用 IntelliJ IDEA 打开 algs4 根目录（pom.xml 已被识别为 Spring Boot 工程）。
2. 运行主类 `com.ds.university.UniversityApplication`。
3. 浏览器访问 <http://localhost:8080/>。

方式二：Maven 命令行

```bash
mvn spring-boot:run
```

方式三：打包后运行

```bash
mvn clean package -DskipTests
java -jar target/algs4-1.0.0.0.jar
```

> 打包会包含前端静态资源（Bootstrap、调度看板 JS 等），jar 可独立部署。

## 6. 测试

集成测试需要本地 MySQL 的 `university` 库可用（真实数据源 + MyBatis），用例运行在事务中自动回滚，不污染示例数据：

```bash
# 只跑大学模块集成测试（工程内其他算法测试较多，建议用 -Dtest 限定）
mvn -Dtest=UniversityIntegrationTest test
```

覆盖：UC-09 统计查询（系预算/工资/选课人数/成绩分布）、选课/退课/成绩录入全流程、重复选课/容量已满/先修未完成/非法成绩等边界场景。

## 7. 常见问题

| 问题 | 处理 |
| --- | --- |
| 8080 端口被占用 | 改用 `--server.port=8081` 启动，或先关闭占用进程 |
| 登录提示数据库错误 | 确认 `university` 库已按第 2 节初始化，`application.yml` 数据源账号密码正确 |
| 中文乱码 | 连接串已带 `characterEncoding=UTF-8`，数据库字符集为 `utf8mb4`；控制台乱码可加 `-Dfile.encoding=UTF-8` |
| 修改代码不生效 | 开发期已引入 `spring-boot-devtools`，改类后自动重启；若未生效检查 IDE 是否开启了自动构建 |
| 需要临时验证页面 | 用 `scripts/start-test-app.ps1 -Port 8081` 启动 8081 实例，验证完删除 `target/app8081*` 与 `target/cp.txt` |
