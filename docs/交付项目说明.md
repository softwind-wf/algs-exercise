# 交付项目说明（卖家版，不要发给买家）

> 本文档是卖家内部备忘，说明干净交付项目 `university-web/` 的由来与使用方法。

---

## 一、为什么有这个干净项目？

原来的 `algs4-master/` 仓库存在两个销售致命问题，已通过分离解决：

| 问题 | 说明 | 处理 |
|---|---|---|
| GitHub 仓库公开 | `softwind-wf/algs-exercise` 为 public，任何人可免费 clone 全部源码 | 你已转私有保留 |
| GPL-3.0 许可证传染 | 仓库含 algs4 算法源码（700+ 文件），LICENSE 为 GPLv3；大学网站代码混在其中，可能被整体视为 GPL 衍生作品，买家有权自由再分发，与"禁止转售"冲突 | 创建独立干净项目 `university-web/`，与 algs4 完全分离 |

**干净项目已验证**：`com.ds.university` 代码零依赖 algs4（无任何 `import edu.princeton`），独立编译通过（exit 0），全部测试通过（exit 0）。

## 二、干净项目包含什么？

```
university-web/                  ← 这就是要卖给买家的东西
├── README.md                    ← 买家第一眼文档（已修正版权声明）
├── pom.xml                      ← 新坐标 com.university:university-web，无 GPL 声明
├── Dockerfile                   ← JAR 名已改为 target/university-web.jar
├── docker-compose.yml           ← 一键部署配置（含独立 Cookie 名 JSESSIONID_DOCKER）
├── .dockerignore / .gitignore
├── src/
│   ├── main/java/com/ds/university/   ← 全部大学网站代码（已带水印）
│   ├── main/resources/               ← 模板/静态资源/mapper/Flyway 迁移/配置
│   └── test/java/com/ds/university/  ← 17 个测试类
├── scripts/                     ← 水印替换等脚本
├── docker/                      ← Maven 镜像配置等
└── keystore/                    ← HTTPS 自签名证书
```

**不包含**（刻意剔除）：
- algs4 算法源码（edu.princeton.cs.algs4 / cn.exercise 等）
- GPL LICENSE 文件
- 根目录散落的算法数据文件（*.txt / *.dat / *.bin 等 34 个）
- 编译产物 target/、运行日志 logs/
- 卖家内部文档（商品简介、上架指南、部署视频脚本——留在 algs4-master 仓库）

## 三、发货流程（每单照做）

1. **替换水印**（一次性，确定署名后执行）：
   ```powershell
   cd D:\downloads\algs4-master\university-web
   powershell -ExecutionPolicy Bypass -File scripts\apply-watermark.ps1
   # 或非交互：... -Name 你的网名 -Force
   ```
2. **验证水印**：`scripts\apply-watermark.ps1 -Check` → 输出"无 YOUR_NAME 残留"
3. **可选验证构建**：
   ```powershell
   $env:JAVA_HOME='C:\Program Files\Java\jdk-1.8'
   mvn -q package -DskipTests
   ```
4. **打包**：整个 `university-web/` 目录压缩为 zip（**不要包含 target/、logs/**），设压缩包密码
5. **上传网盘** → 发链接+提取码 → 付款后发压缩包密码 → 附《买家售后FAQ.md》

## 五、注意事项

- **原仓库 `algs4-master/` 保持不动**：它仍是你的开发工作区，GitHub 私有仓库继续保留作算法练习/历史存档。
- **不要再把 `university-web/` 推送到公开 GitHub**：交付用网盘，GitHub 只保留私有。
- **水印署名**：发货前必须替换 YOUR_NAME（脚本防呆强制），防止买家转售无法追溯。
- 干净项目每次改代码后，记得同步 `mvn compile` 验证（Java 8 + 独立构建，已验证通过）。
