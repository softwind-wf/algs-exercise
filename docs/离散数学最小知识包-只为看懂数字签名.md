## 0. 先回答"原理需不需要搞懂"

分三层看：

| 层 | 内容 | 不懂的后果 |
|---|---|---|
| **必须懂（概念级，半天）** | hash 干什么；签名 = 私钥生成 / 公钥验证 / 返回布尔；签名覆盖什么；公钥从哪来 | 会用错 API：签了等于没签、验签形同虚设 |
| **值得懂（解释级，各 10 分钟）** | 欧拉定理的**结论**、CRT 的"分开算再合并"、平方-乘的**规则**、模逆 | 能正确用库，但说不清"为什么安全"，遇到变体容易慌 |
| **可以不懂（证明级）** | 欧拉定理的证明、Miller-Rabin 为什么对、RSA 安全归约、λ(n) vs φ(n) 的取舍 | 不影响工程使用，不影响正确实现 |

所以：

- **要做对数字签名**：不需要啃离散数学。用标准库（Ed25519 / RSA-PSS），概念层那几条懂了就够；
- **要判断"看到的东西对不对"**：需要这四块的"结论版"。比如教材那句"私钥加密即签名"，你只要知道
  "签名要先 hash、验证是布尔"，就能看出它省掉了什么；
- **要自己发明/修改密码方案**：才需要证明级的东西——而且正常工作里没人该这么干。

一个类比：开车不需要懂发动机热效率，但要懂仪表盘（油量、水温、故障灯）。
签名工程的"仪表盘"是：hash、填充、覆盖范围、公钥来源；发动机是欧拉定理和 CRT。

**但这不等于"可以照简化说法实现"**——教材那句"私钥加密即签名"，照字面写就是坏的（见
[数字签名-教材没说的部分.md](<docs/数字签名-教材没说的部分.md>)）。
"不懂原理"的安全用法是：**用标准库 + 标准算法名**；危险用法是：**按直觉自己拼**。

## 1. 模运算与模逆（15 分钟）

**模运算**就是"取余数"：`a mod n` 是 a 除以 n 的余数。
两个数"模 n 同余"记作 `a ≡ b (mod n)`，意思是 `a - b` 能被 `n` 整除。

例：`65^17 mod 3233 = 2790`，读作"65 的 17 次方，除以 3233 的余数是 2790"。

**模逆元**：找一个 `d`，使 `e·d ≡ 1 (mod n)`。它就是"模世界里的倒数"。

例（本文一直用的那组数）：

```text
e = 17, φ(n) = 3120
17 × 2753 = 46801 = 15 × 3120 + 1
所以 17 × 2753 ≡ 1 (mod 3120)     →  d = 2753
```

### 1.1 怎么找 d：先看一个更小的例子（3 在模 7 下求逆）

目标：找 d 使 `3d ≡ 1 (mod 7)`，也就是 3d 除以 7 余 1。

```text
第 1 步 做带余除法：7 = 2*3 + 1      ← 余数 1，停
第 2 步 把余数 1 写成"7 和 3 的组合"：
        1 = 7 - 2*3
        模 7 下 7 ≡ 0，所以 1 ≡ -2*3 (mod 7)
        => d = -2 ≡ 5 (mod 7)
验证：3 * 5 = 15 = 2*7 + 1          ✓
```

关键：**不是猜 d，而是把"余数 1"反着写成原始数的组合，系数就是 d。**

### 1.2 换到 3120 和 17：-367 是这么来的

```text
3120 = 183 * 17 + 9      (1)
17   = 1   * 9  + 8      (2)
9    = 1   * 8  + 1      (3)
8    = 8   * 1  + 0      (4)   ← 余数 0，停；上一行的余数 1 就是 gcd
```

从 (3) 开始，把余数 1 逐层替换成 17 和 3120 的组合（这就是"回代"）：

```text
(3)  1 = 9 - 1*8
     代入 (2) 的 8 = 17 - 1*9：
     1 = 9 - (17 - 1*9) = 2*9 - 17
     代入 (1) 的 9 = 3120 - 183*17：
     1 = 2*(3120 - 183*17) - 17
       = 2*3120 - 366*17 - 17
       = 2*3120 - 367*17
```

所以 `1 = 17*(-367) + 3120*2`；在模 3120 下 `3120*2 ≡ 0`，于是：

```text
17 * (-367) ≡ 1 (mod 3120)
```

**-367 就是 17 的系数**（3120 的系数是 2）。私钥要正数，加一个 3120 不改变余数：

```text
d = -367 + 3120 = 2753
验证：17 * 2753 = 46801 = 15*3120 + 1      ✓
```

### 1.3 不想做代数回代：表格法（代码就是这么算的）

每行满足 `r = s·17 + t·3120`，只记 17 的系数 `s`；
规则只有一条：**下一行的 s = 上一行的 s − 商 × 当前行的 s**。

| r | 商 | s（17 的系数） | 怎么来的 |
|---|---|---|---|
| 3120 | – | 0 | 初始 |
| 17 | – | 1 | 初始 |
| 9 | 183 | −183 | 0 − 183×1 |
| 8 | 1 | 184 | 1 − 1×(−183) |
| 1 | 1 | **−367** | −183 − 1×184 |
| 0 | 8 | – | 停 |

最后一行非零余数 1 对应系数 −367，即 `1 = 17×(−367) + 3120×2`，`d = −367 + 3120 = 2753`。

想直接看机器跑出来的过程：`.\scripts\run-rsa-principles-demo.ps1` 的第【4】段会把除法链、回代、
表格法和验证全部打印出来（`docs/rsa-principles-raw.txt`）。

**练一题**：求 7 在模 26 下的逆元。
提示：`26 = 3*7 + 5`、`7 = 1*5 + 2`、`5 = 2*2 + 1`；回代得 `1 = 3*26 - 11*7`，
所以 `d = -11 + 26 = 15`，验证 `7*15 = 105 = 4*26 + 1`。

**签名里用在哪**：私钥 `d` 就是 `e` 在模 `φ(n)` 下的逆元。不知道 `φ(n)` 就算不出 `d`，
而 `φ(n)` 只有知道 `p`、`q` 才能算——这就是"私钥只有一把"的算术来源。

## 2. 欧拉定理：只需要记住一条结论

不需要会证明，只需要记住并会用这一条：

> 若 `gcd(m, n) = 1`，则 `m^φ(n) ≡ 1 (mod n)`。

其中 `φ(n)` 是"1 到 n−1 里与 n 互素的数的个数"。对两个素数乘积：`φ(pq) = (p−1)(q−1)`。

例：`φ(3233) = 60 × 52 = 3120`，于是 `2^3120 mod 3233 = 1`、`65^3120 mod 3233 = 1`。

**它为什么能解释"解密"**（三次初等变形，不需要更深的数学）：

```text
c^d = (m^e)^d = m^(e·d)                 ← 幂的幂：指数相乘
e·d ≡ 1 (mod φ)  ⇒  e·d = 1 + k·φ       ← 本文 e·d = 46801 = 1 + 15×3120，k = 15
m^(1+kφ) = m · (m^φ)^k                  ← 指数相加：m^(A+B) = m^A · m^B
        ≡ m · 1^k = m (mod n)           ← m^φ ≡ 1（欧拉定理），1^k = 1
```

把最后一行拆开，就两次替换：

1. **`m^(1+kφ) = m · (m^φ)^k`**：纯指数法则 `m^(A+B) = m^A·m^B`、`m^(kφ) = (m^φ)^k`，与模无关；
2. **`(m^φ)^k ≡ 1^k`**：欧拉定理给 `m^φ ≡ 1 (mod n)`；而"同余"在乘方下保持——
   若 `a ≡ b (mod n)`，则 `a^k ≡ b^k (mod n)`。再 `1^k = 1`，就得到 `m`。

**用最小数字手算一遍**（n=7, φ(7)=6, m=2, 取 k=2）：

```text
2^6 = 64 = 9×7 + 1          ⇒ 2^6 ≡ 1 (mod 7)        ← 欧拉定理
2^(1+2×6) = 2^13 = 8192 = 2×(2^6)^2 = 2×4096
按 m·(m^φ)^k 算：2 × 1^2 = 2
直接算：8192 = 1170×7 + 2   ⇒ 2^13 mod 7 = 2
两者一致。
```

换算成 RSA 的数字（m=65, n=3233, φ=3120, e·d=46801）：`65^3120 mod 3233 = 1`，
所以 `65 × 1^15 = 65`；直接算 `65^46801 mod 3233` 也是 65（演示程序第【2】段有实测）。

**签名里用在哪**：解释"为什么用私钥算出来的东西，公钥能验回去"——
因为 `e·d ≡ 1`，两个方向的幂运算互为逆。**也解释了为什么 `φ(n)` 必须是秘密**：
知道 `φ(n)` 就能立刻算出 `d`（实测：`e^-1 mod 3120 = 2753`）。

> 注意：欧拉定理要求 `m` 与 `n` 互素；RSA 实际对所有 `m` 都成立，靠的是下一节的 CRT。

## 3. 中国剩余定理：只需要"分开算，再合并"

### 3.1 最小例子：mod 3 和 mod 5 拼出 mod 15

已知 `x mod 3 = 2`、`x mod 5 = 4`，x 只可能在 0..14 里（3×5=15 循环一次）：

```text
满足 x mod 3 = 2 的候选：2, 5, 8, 11, 14
其中谁还满足 x mod 5 = 4？
  2 mod 5 = 2    5 mod 5 = 0    8 mod 5 = 3    11 mod 5 = 1    14 mod 5 = 4  ✓
所以 x = 14 (mod 15)
```

**关键观察**：0..14 这 15 个数，给出的 `(mod 3, mod 5)` 组合恰好 15 种、互不相同——
"两个余数"和"0..14 里的一个数"是一一对应的。这就是 CRT 的全部内容。

### 3.2 怎么算出来，而不是一个个试

给每个条件配一个"只在它自己那儿是 1、在别人那儿是 0"的零件：

```text
M = 3×5 = 15
零件1（管 mod 3）：M1 = 5，要 5·y1 ≡ 1 (mod 3) → y1 = 2（5×2=10≡1）→ 零件 = 5×2 = 10
零件2（管 mod 5）：M2 = 3，要 3·y2 ≡ 1 (mod 5) → y2 = 2（3×2=6≡1） → 零件 = 3×2 = 6
验证：10 mod 3 = 1、10 mod 5 = 0；6 mod 3 = 0、6 mod 5 = 1

拼起来：x = 2×10 + 4×6 = 20 + 24 = 44 ≡ 14 (mod 15)     ✓
```

零件构造规则：`Mi = M / 除数`，再乘 `Mi` 自己的逆元。

### 3.3 RSA 里那个 1220 就是这么来的

```text
x ≡ 0 (mod 61)、x ≡ 1 (mod 53)，M = 61×53 = 3233
零件1（管 mod 61）：53 × 53⁻¹ mod 61 = 53 × 38 = 2014   （mod 61 为 1，mod 53 为 0）
零件2（管 mod 53）：61 × 61⁻¹ mod 53 = 61 × 20 = 1220   （mod 61 为 0，mod 53 为 1）

x = 0×2014 + 1×1220 = 1220
```

所以 `1220` 不是猜的，它正好是**零件 2 = 61×20**：mod 61 下是 0，mod 53 下是 1。

### 3.4 为什么要求 p、q 互素

`mod 4` 与 `mod 6` 不互素（gcd=2），就会"凑不出来"：

```text
x ≡ 0 (mod 4)，x ≡ 1 (mod 6)
x mod 4 = 0 ⇒ x 是偶数；x mod 6 = 1 ⇒ x 是奇数 —— 矛盾，无解
```

RSA 的 p、q 是两个不同素数，必然互素，所以任意两个余数都能拼出唯一的 x。

### 3.5 签名 / RSA 里用在哪（两处，都不需要会推导）

1. **补欧拉定理的缺口**：`m` 是 `p` 或 `q` 的倍数时，欧拉定理不成立；但分模 `p`、`q` 各看一遍，
   两边都成立，合起来（CRT）就成立。所以 RSA 对所有 `m` 都对。
2. **加速私钥运算**：不用算 `c^d mod n`，而是算 `c^dP mod p`、`c^dQ mod q` 再拼起来。
   用本文的小数字验证：`m1 = 2790^2753 mod 61 = 4`、`m2 = 2790^2753 mod 53 = 12`，
   `qInv = 53⁻¹ mod 61 = 38`，`h = 38×(4−12) mod 61 = 1`，`m = 12 + 1×53 = 65` ✓
   （两个一半长度的运算约快 3 倍，实测约 4.5 ms → 1.5 ms。）

JDK 的私钥对象里多存的那几个参数（`p, q, dP, dQ, qInv`）就是为这个准备的。
完整过程可看演示第【3】段：`.\scripts\run-rsa-principles-demo.ps1`。

## 4. 快速模幂（平方-乘）：会照规则手算就行

"快速模同余幂算法"听起来吓人，规则只有一句：

> 把指数写成二进制，从最高位开始读：**每一位都先平方，该位是 1 再乘一次底数**，每步都取模。

手算 `65^17 mod 3233`（17 = `10001` 二进制，5 位）：

| 步骤 | 二进制位 | 动作 | 结果 |
|---|---|---|---|
| 1 | 1 | 平方（=1）+ 乘 65 | 65 |
| 2 | 0 | 平方 | 992 |
| 3 | 0 | 平方 | 1232 |
| 4 | 0 | 平方 | 1547 |
| 5 | 1 | 平方 + 乘 65 | 2790 |

验算：`65² = 4225 ≡ 992`；`992² ≡ 1232`；`1232² ≡ 1547`；`1547² ≡ 789`；`789×65 ≡ 2790`。

**为什么必须每步取模**：不取模的话，`65^17` 已经是 31 位数，`2048^2046` 是六千多位，
而且每平方还会再翻一倍；每步取模后数值永远不超过 `n`。

**复杂度**：指数 `e` 有 `k` 位，就做 `k` 次平方 + "1 的个数"次乘法，即 `O(log e)`。
2048 位私钥的 `d` 约 2045~2047 位 → 约 2046 次平方 + 1000 次左右乘法 → 几毫秒算完。
（这才叫"快速"：naive 要乘 `d` 次。）

**签名里用在哪**：RSA 的加密、解密、签名、验签全是它；ECC/Ed25519 的标量乘是它的"曲线版"。

## 5. "不懂原理也能安全用" vs "不懂原理一定会翻车"

| 做法 | 需要懂什么 | 结果 |
|---|---|---|
| 用 `Signature.getInstance("Ed25519")` 签/验 | 只需要知道"私钥签、公钥验、返回布尔" | 安全 |
| 用 `"RSASSA-PSS"` + 参数 | 同上 + 知道"签/验参数必须一致" | 安全 |
| 按教材"私钥加密、公钥解密"自己拼 | 需要懂 hash/填充/长度 | **坏的**：只能签 255 字节、可伪造 |
| 验签只判断"解密成功" | 需要懂"验证是布尔" | **坏的**：等于不验签 |
| 自己实现 RSA 填充 | 需要懂填充结构与解析 | **坏的**：历史漏洞都出在这 |

所以"原理需不需要懂"的准确回答是：

- **签名要正确使用**：只需要概念层（hash、方向、布尔、覆盖范围）；
- **要识别错误说法**：需要这四块的结论版（本文）；
- **要自己实现密码学**：需要证明级——但请别做。

## 6. 五分钟自测（答案在文末）

1. 17 在模 3120 下的逆元是多少？怎么验证？
2. 为什么 `e·d ≡ 1 (mod φ)` 能让 `m^(ed) ≡ m`？
3. `x ≡ 0 (mod 61)`、`x ≡ 1 (mod 53)`，`x mod 3233` 是多少？
4. 用平方-乘算 `65^17 mod 3233`，需要几次平方、几次乘法？
5. 数字签名里 hash 和填充各防什么？

<details>
<summary>答案</summary>

1. 2753；`17 × 2753 = 46801 = 15×3120 + 1`，所以乘积模 3120 余 1。
2. `e·d = 1 + kφ`，所以 `m^(ed) = m·(m^φ)^k`；由欧拉定理 `m^φ ≡ 1`，得 `m·1^k = m`。
3. 1220（`1220 = 20×61`，且 `1220 mod 53 = 1`）。
4. 5 次平方 + 2 次乘法（指数 5 位、其中 2 个 1）。
5. hash：把任意长消息压成固定长度，并破坏可乘性、抗碰撞；填充：让"自己拼出来的签名"几乎不可能满足结构，防伪造与跨算法替换。

</details>

## 8. 一张图记住整条链

```text
φ(n)（秘密） ──> d = e^-1 mod φ ──┐
                                  ├──> 私钥 d：算 m^d（签名/解密）
n = p·q（公开） ──> 公钥 (n, e) ──┘
                                  └──> 公钥 e：算 s^e（验签/加密）

签名：s = H(m)^d mod n        （先 hash，再填充，再模幂）
验证：s^e mod n == H(m) ?     （返回 true/false）
```
