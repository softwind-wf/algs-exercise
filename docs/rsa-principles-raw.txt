【1】小素数全流程：p=61, q=53（所有数字都能手算）
==================================================================
第 1 步 选两个素数：p = 61，q = 53
第 2 步 模数 n = p*q = 3233（这是公开的，2048 位密钥就是 2048 位的 n）
第 3 步 欧拉函数 φ(n) = (p-1)(q-1) = 3120（这是秘密，等价于 p、q 本身）
第 4 步 公钥指数 e = 17（通常取 65537，这里为了手算取小的）
第 5 步 私钥指数 d = e^-1 mod φ(n) = 2753（e 在模 φ 下的乘法逆元）
       验证 e*d = 46801 = 15 * 3120 + 1，即 e*d ≡ 1 (mod φ(n))
  [通过] e*d ≡ 1 (mod φ(n))
公钥 (n, e) = (3233, 17)
私钥 (n, d) = (3233, 2753)

第 6 步 加密：c = m^e mod n，m = 65（'A'）
  m^e：底数 65，指数 17 = 0b10001（5 位）
  bit 1/5 = 1 -> 平方 + 乘底数 -> 65
  bit 2/5 = 0 -> 平方 -> 992
  bit 3/5 = 0 -> 平方 -> 1232
  bit 4/5 = 0 -> 平方 -> 1547
  bit 5/5 = 1 -> 平方 + 乘底数 -> 2790
  共 5 次平方、2 次乘底数（naive 要 17 次乘法）
  => 密文 c = 2790
  [通过] 65^17 mod 3233 = 2790

第 7 步 解密：m' = c^d mod n，c = 2790
  c^d：底数 2790，指数 2753 = 0b101011000001（12 位）
  bit 1/12 = 1 -> 平方 + 乘底数 -> 2790
  bit 2/12 = 0 -> 平方 -> 2269
  bit 3/12 = 1 -> 平方 + 乘底数 -> 2393
  bit 4/12 = 0 -> 平方 -> 806
  bit 5/12 = 1 -> 平方 + 乘底数 -> 3213
  bit 6/12 = 1 -> 平方 + 乘底数 -> 615
  bit 7/12 = 0 -> 平方 -> 3197
  bit 8/12 = 0 -> 平方 -> 1296
  bit 9/12 = 0 -> 平方 -> 1689
  bit 10/12 = 0 -> 平方 -> 1215
  bit 11/12 = 0 -> 平方 -> 1977
  bit 12/12 = 1 -> 平方 + 乘底数 -> 65
  共 12 次平方、5 次乘底数（naive 要 2753 次乘法）
  => 明文 m' = 65（'A'）
  [通过] c^d mod n 还原出原始 m

整条链路：m -> m^e -> c -> c^d -> m。中间没有任何"查表"，全靠模幂运算。

==================================================================
【2】为什么 d 能把 m 还原：欧拉定理 + e·d ≡ 1
==================================================================
要证：c^d ≡ m (mod n)，其中 c = m^e。
c^d = (m^e)^d = m^(e*d)
e*d ≡ 1 (mod φ(n))  ==>  e*d = 1 + k*φ(n)，这里 e*d = 46801 = 1 + 15*3120
  [通过] e*d 确实等于 1 + k*φ(n)（k = 15）
所以 m^(e*d) = m^(1 + k*φ(n)) = m * (m^φ(n))^k
  这一步只是指数法则：m^(A+B) = m^A * m^B，m^(k*φ) = (m^φ)^k。

欧拉定理：gcd(m, n) = 1 时，m^φ(n) ≡ 1 (mod n)。
代入：(m^φ(n))^k ≡ 1^k = 1，所以 m * (m^φ(n))^k ≡ m (mod n)。证毕。

—— 用小到能手算的数字走一遍（n=7, φ(7)=6, m=2, k=2）——
  2^6 mod 7 = 1（欧拉定理）
  2^(1+2*6) = 2^13 = 8192 = 2*(2^6)^2 = 2*64^2
  按 m*(m^φ)^k 算：2 * 1^2 = 2
  直接算 2^13 mod 7 = 2
  [通过] 2^13 mod 7 = 2，两种算法一致

—— 换成 RSA 的数字（m=65, n=3233, φ=3120, e*d=46801, k=15）——
  m^φ mod n = 1（欧拉定理）
  m·(m^φ)^k = 65 * 1^15 = 65
  直接算 65^46801 mod 3233 = 65
  [通过] 65^46801 mod 3233 = 65，与推导一致

实测 m^φ(n) mod n：
  m = 2 -> m^3120 mod 3233 = 1
  m = 3 -> m^3120 mod 3233 = 1
  m = 65 -> m^3120 mod 3233 = 1
  m = 1000 -> m^3120 mod 3233 = 1
  [通过] gcd(m,n)=1 的样本都满足 m^φ(n) ≡ 1 (mod n)

注意：这个推导默认了 m 与 n 互素。RSA 实际上对所有 m 都成立，见第 3 段。

==================================================================
【3】进阶：m 与 n 不互素时欧拉定理失效，但 RSA 仍然正确
==================================================================
取 m = p = 61（与 n 不互素，欧拉定理不适用）：
  m^φ(n) mod n = 1220 ≠ 1（欧拉定理确实不成立）
  但 m^(e*d) mod n = 61，依然还原
  [通过] 不互素时 RSA 依然正确（靠中国剩余定理）

原因：分别看模 p 和模 q。
  mod p：m ≡ 0，两边都是 0；
  mod q：m 与 q 互素，欧拉定理成立，两边都是 m；
  两个同余式合起来（CRT），就对所有 m 成立。

—— CRT 最小例子：mod 3 和 mod 5 拼出 mod 15 ——
已知 x mod 3 = 2，x mod 5 = 4。x 只可能在 0..14（3*5=15 一循环）：
  满足 x mod 3 = 2 的候选：2 5 8 11 14
  其中 x mod 5 = 4 的只有 14  =>  x = 14 (mod 15)
  [通过] 0..14 的 15 个数给出 15 组互不相同的 (mod 3, mod 5)（一一对应）
  构造法：零件1 = 5 * 5^-1 mod 3 = 5*2 = 10（mod 3 为 1，mod 5 为 0）
          零件2 = 3 * 3^-1 mod 5 = 3*2 = 6（mod 3 为 0，mod 5 为 1）
          x = 2*10 + 4*6 = 14 (mod 15)
  [通过] 构造法同样得到 14

—— 用同样的办法拼出 RSA 里的 1220 ——
  零件1（管 mod 61）：53 * 53^-1 mod 61 = 53 * 38 = 2014，它 mod 61 = 1，mod 53 = 0
  零件2（管 mod 53）：61 * 61^-1 mod 53 = 61 * 20 = 1220，它 mod 61 = 0，mod 53 = 1
  x ≡ 0 (mod 61), x ≡ 1 (mod 53)  =>  x = 0*2014 + 1*1220 = 1220
  [通过] 拼出的 x = 1220

—— CRT 加速私钥：在 p、q 上各算一半，再拼回去 ——
  m1 = 2790^2753 mod 61 = 4（= 65 mod 61）
  m2 = 2790^2753 mod 53 = 12（= 65 mod 53）
  qInv = 53^-1 mod 61 = 38，h = qInv*(m1-m2) mod 61 = 38*(4-12) mod 61 = 1
  m = m2 + h*q = 12 + 1*53 = 65
  [通过] 两个半长运算拼回同一个 m=65
  [通过] 与直接算 c^d mod n 的结果一致
实现上，CRT 也正是私钥运算加速的原理（第 5 段）。

==================================================================
【4】从 e 和 φ(n) 算出 d：扩展欧几里得（-367 是怎么来的）
==================================================================
目标：找 d 使 17*d ≡ 1 (mod 3120)。

第 1 步 欧几里得除法链（只做带余除法，就是长除法）：
  3120 = 183 * 17 + 9
  17 = 1 * 9 + 8
  9 = 1 * 8 + 1
  8 = 8 * 1 + 0
  余数为 0 时停，上一行的余数 1 就是最大公约数。

第 2 步 回代：把 1 一路换成 17 和 3120 的组合（从最后一条非零余数往上代）：
  1 = 9 - 1*8
    = 9 - (17 - 1*9)              = 2*9 - 17
    = 2*(3120 - 183*17) - 17      = 2*3120 - 367*17
  所以 1 = 17*(-367) + 3120*2，即 17*(-367) ≡ 1 (mod 3120)。
  这里的 -367 就是 17 的系数（3120 的系数是 2）。

第 3 步 表格法（实际计算用这个，不用做代数回代）：
  每行满足 r = s*17 + t*3120，只记 17 的系数 s；
  规则：下一行的 s = 上一行的 s - 商 * 当前行的 s。

  r         商       s（17 的系数）
  3120      -       0
  17        -       1
  9         183     -183  = 0 - 183*1
  8         1       184  = 1 - 1*-183
  1         1       -367  = -183 - 1*184
  0         8       （余数 0，停）

  最后一行非零余数 1 对应系数 -367，即 1 = 17*(-367) + 3120*2。
  负数换成 0..3119 的正数：-367 + 3120 = 2753
  验证：17 * 2753 = 46801 = 15 * 3120 + 1
  [通过] 17 * d ≡ 1 (mod 3120)
  [通过] d = 2753
  [通过] 与 BigInteger.modInverse 结果一致

【5】真实 2048 位：密钥生成、CRT 加速
==================================================================
生成 2048 位密钥耗时: 205 ms
n 位数: 2048 位（十进制约 617 位）
e = 65537（固定 65537 = 2^16+1，二进制 1 0000 0000 0000 0001，只有 2 个 1 → 加密/验签只要 17 次模乘）
d 位数: 2046 位（几乎和 n 一样长，私钥运算慢就慢在这里）
CRT 参数: p 1024 位, q 1024 位, dP 1024 位, dQ 1024 位

解密同一条密文（10 次平均）：
  直接算 c^d mod n      : 3.821 ms
  CRT: 模 p、模 q 再合并 : 1.090 ms
  加速比约 3.5 倍
  [通过] 两种解密结果都等于原文
  [通过] CRT 加速确实更快（JDK 的私钥内部就用它）

密钥生成的本质：找两个 1024 位素数（Miller-Rabin 反复试），算 φ、选 e=65537、用扩展欧几里得求 d。

【6】为什么安全性落在"分解 n 难"：知道 φ 就等于知道 d
==================================================================
攻击者知道公钥 (n=3233, e=17)，但不知道 p、q。
假设攻击者暴力枚举出 φ(n) = 3120（真实世界做不到，见下）：
  他立刻能算 d' = e^-1 mod φ(n) = 2753 —— 就是私钥 d
  [通过] 知道 φ(n) 即可算出私钥 d
  用 d' 解密 c = 2790 -> 65（原文 65）
  [通过] φ 泄露 = 私钥泄露

而 φ(n) = (p-1)(q-1) 只依赖 p、q。所以：
  会分解 n  -> 得到 p、q -> 得到 φ -> 得到 d -> 能解密/伪造签名
  反过来，已知 d 也能分解 n（概率多项式时间，教材里通常不讲）。

规模感（公开记录）：
  RSA-250（829 位）2020 年被分解，约 2700 核·年；
  RSA-2048（2048 位）至今没有被分解，是目前公认的安全底线；
  RSA-1024 已不安全，RSA-512 早就被业余算力攻破。
所以 RSA 的安全边界不是"算法保密"，而是"分解 n 的计算量"。
