实体集 person 的特化：employee / student

Specialization（特化）：把实体集 person 按属性差异划分为子集 employee 与 student

依据《数据库系统概念》第 7 章扩展的 E-R 特性（7.8.1 特化）— Chen 记号

实体集 属性 ISA 特化/概化 连接（父子集、实体—属性） 下划线属性 = 主键

矢量版：person-specialization.svg（可直接插入 Word / PPT 并无损缩放）；位图版：person-specialization-er.png

语义

  • 特化（specialization）：从实体集 person 中，按属性差异分出子集 employee 与 student。
  • 概化（generalization）：反过来，由 employee 与 student 的共同属性（ID、name、address）归纳出 person。
  • ISA 关系：每个 employee / student 实体同时也是一个 person 实体——属性继承，无需重复存储。

约束（可标注在 ISA 上）

  • 部分 / 全特化：本例用单线表示部分特化——一个人可以既非雇员也非学生。
  • 不相交 / 重叠：教材示例允许“是雇员、是学生、都是、都不是”，即重叠（overlapping）。
  • 若改为全特化用双线连到 ISA；若改为不相交，则在 ISA 旁标注 d（disjoint）。

属性清单

  • person：ID（主键）、name、address
  • employee：继承三者 + salary
  • student：继承三者 + tot_cred

对应的关系模式

person  (ID, name, address)
employee(ID, name, address, salary)
student (ID, name, address, tot_cred)

若子实体集为部分特化，employee / student 中只出现各自子集的 person；其余 person 仅存在于 person 关系中。
